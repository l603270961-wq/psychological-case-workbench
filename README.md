这是什么
中国大量中小学没有专职心理教师。当一名学生出现情绪问题，最先发现、最先要做出判断的，往往不是接受过系统训练的心理专业人员，而是班主任、大队辅导员一类非专业一线教师。

我们能看见孩子的状态，但写下来只是"今天她又哭了"。我们知道事情不对劲，但说不出"这算不算严重"。我们想求助，但不知道怎么把情况讲清楚还不暴露孩子的隐私。

心理个案工作台是为这些一线非专业观察者开发的工具。它不替代专业心理老师做诊断——那是 AI 不应承担的事。但它帮我们把白描变成专业记录，帮我们识别判断尺度，帮我们把脱敏后的档案清晰地交到真正专业的人手里。

谁适合用
没有专职心理教师、由大队辅导员/班主任承担心理工作的小学
一位心理教师同时跟进数十个个案、记录工作压力大的学校
需要在多位老师之间交接学生跟进情况的德育部门
需要向校外心理咨询师、医院儿童心理科做脱敏转介的一线教育者
核心功能
双模式数据看板——总览模式呈现全校在跟进个案的统计、风险等级分布、行为类别分布、今日待办；个案模式聚焦单个学生的情绪强度时间趋势曲线、历次观察时间线。

白描录入与 AI 翻译——老师写白描（"今天小陈说妈妈骂他笨，他把试卷撕了"），AI 翻译为四段专业叙述（行为表现 / 情绪与认知 / 可能成因 / 干预建议），并生成结构化标签（行为类别 / 情绪强度 / 风险等级）。AI 原始判断与教师最终判断双值保留。

四种受众智能导出——同一份档案一键导出为班主任版（信件）、家长版（信件）、学校上级版（公文）、专业同行版（9 段标准心理咨询个案报告）。专业同行版的"评估与诊断"段必须从 AI 三个候选中选择或重写——这条规则写死在代码里，是工程化的伦理边界。

化名/真名双层密码分离——主密码保护工具访问，姓名解锁密码独立加密化名→真名映射表。真名只在解锁后 15 分钟内可见，倒计时结束自动锁回。原始数据全部本机存储，AI 调用前完成脱敏。

快速开始
只需要一个浏览器和一个 DeepSeek API Key。

下载 HTML 文件：点击仓库中的 心理个案工作台_小学版_v4.html，右上角点 Download raw file。
双击打开：在 Chrome、Edge 或 Firefox 浏览器中打开下载的 HTML 文件。
首次设置：跟随引导设置主密码、可选设置姓名保护密码、填入 DeepSeek API Key。
从演示模式开始：首次进入工具自动加载演示模式，3 个示范学生（陈/赵/林）展示工具完整工作流。
演示模式说明：工具内置了三个虚构学生的完整剧情骨架，分别展示"改善弧"、"波动弧"、"恶化转介弧"三种典型心理工作场景。所有演示数据均为虚构，与任何真实学生无关。退出演示模式后，所有演示数据可一键清空，进入正式工作环境。

DeepSeek API Key 怎么获取
访问 https://www.deepseek.com/ 注册账号，在 "API Keys" 页面创建一个 Key。
设计原则
单文件部署——全部代码（约 4900 行）封装在一个 HTML 文件中，无需安装任何软件，无需任何环境配置。浏览器即是运行环境。

数据本地存储——所有学生档案、跟进记录、姓名映射表均存储在浏览器 LocalStorage 中，原始数据不出本机。AI 调用前对学生信息做脱敏处理。

AI 辅助而非替代——AI 承担结构化与候选生成，教师承担最终判断。专业同行版"评估与诊断"和"个案概念化"两段必须从 AI 三个候选中选择或重写，这条规则不是使用建议，而是写死在代码里的工程约束。

双值记录——每次跟进同时保留 AI 的原始判断和教师的最终判断。这两个值的差异点本身就是一种长期训练判断尺度的素材。

技术栈
单文件 HTML + 原生 JavaScript（无打包工具、无构建步骤）
LocalStorage 本地存储
Web Crypto API（PBKDF2 + AES-GCM 加密真名映射表）
ECharts（数据可视化，通过 jsdelivr CDN 引入）
DeepSeek API（应用层 AI 能力）
